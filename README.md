# Solving Partial Differential Equations Using Metaheuristic Algorithms

This repository contains the original research implementation for solving partial differential equation (PDE) problems using metaheuristic optimization algorithms.

The work explores four optimization algorithms:

- Bald Eagle Search (BES)
- Particle Swarm Optimization (PSO)
- Genetic Algorithm (GA)
- Whale Optimization Algorithm (WOA)

## Original implementation

The complete research code, experiment workflow, and saved outputs are preserved in the original Jupyter Notebook:

[`Finall_ALL_AL_PDE.ipynb`](./Finall_ALL_AL_PDE.ipynb)

For now, this notebook is the only source of implementation in the repository. No separate Python package, reorganized modules, or additional project structure is provided.

## Method overview

To apply the approach to a PDE problem, the problem is formulated as an objective (fitness) function and an appropriate approximation function is selected. The metaheuristic algorithms are then used to optimize the approximation parameters.

Please refer to the notebook for the actual implementation details, problem formulations, experiments, and results.
